# Project-Hermes-Vayu
There are two file the Project HERMES VAYU is the encryption one while the Project HERMES VAYU-D is the decryption one.
A multi-stage custom cryptographic encryption algorithm featuring keyword substitution, forward/backward chain mixing, and S-Box transformations.
This is custom project that I have been working on. Just exploring the cryptography as i felt it was cool.
Phase 1: It uses Keyword Substitution, here the custom keyword is COURTAB
Phase 2: It uses Numeric mapping to convert the alphabets to number for further mixing or as the technical term Permutation
Phase 3: Diffusion and Permutation
Phase 4: S-box transformation to create non linear confusion
